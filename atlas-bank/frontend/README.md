# Atlas Bank — Frontend (React)

Interface de la banque en ligne Atlas Bank.

## Lancer le projet

```bash
npm install
npm start
```

Ouvrir http://localhost:3000

L'API backend doit tourner sur http://localhost:3001
(voir `../backend/README.md`).

Compte de démonstration : demo@atlasbank.ma / demo123

## Écrans

- **Login** : connexion / inscription.
- **Dashboard** : solde total, liste des comptes, création de compte,
  dépôt et retrait.
- **Virement** : envoi d'argent vers un autre compte (par numéro).
- **Historique** : transactions d'un compte, avec le solde après
  chaque opération.
